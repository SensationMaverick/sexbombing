# Sex Bombing — website

Live site for sexbombing.co.uk. Plain HTML and one stylesheet, no build step,
published by Cloudflare Pages (same approach as the Sensation Maverick site).

| File | What it is |
|---|---|
| `index.html` | Home: the journey, the night, who it's for, the pack |
| `road-trip.html` | Points, challenges and convoy rules |
| `faq.html` | Questions and answers |
| `styles.css` | Every style, in one place |
| `images/` | Logos (transparent PNG) |

Header, footer and the 18+ gate are repeated on each page. Change one, change all three.

## Rules for content

Keep it non-explicit. Public copy never describes sexual activity in detail, so
the site stays safe for ad platforms and payment partners. Exact venue and
checkpoint locations are never published here.
